# Спецификация: Веб-ресурс строительной компании «Nordic Craft» (Кейс для портфолио)

**Дата:** 18 августа 2026  
**Статус:** Согласовано  
**Цель:** Создание высококонверсионного, быстрого и адаптивного веб-ресурса для строительной компании премиум/комфорт сегмента с интерактивным квиз-калькулятором стоимости и интеграцией с CRM/Telegram.

---

## 1. Концепция и позиционирование

* **Бренд:** «Nordic Craft Architecture & Construction» — малоэтажное загородное строительство под ключ с фиксированной сметой и гарантией 10 лет.
* **Целевая аудитория:** Клиенты, планирующие строительство загородного дома (газобетон, фахверк, каркас, кирпич), ценящие прозрачность сметы, скандинавскую эстетику и надежность.
* **Главная цель сайта:** Прямые продажи, захват квалифицированных лидов через пошаговый расчет сметы, демонстрация экспертизы через детализированные кейсы.

---

## 2. Дизайн-система и визуальный стиль

* **Стиль:** «Nordic / Premium Minimal» — строгий, сбалансированный скандинавский минимализм без визуального шума.
* **Цветовая палитра:**
  * Background Light: `#F9FAFB` (мягкий молочно-белый)
  * Surface / Card: `#FFFFFF` (чистый белый с деликатными тенями и тонкими рамками `rgba(0, 0, 0, 0.06)`)
  * Background Dark (Hero / Accent blocks): `#12151A` (глубокий графитово-угольный)
  * Primary Accent: `#D48B46` / `#C27329` (теплая благородная охра / обожженная глина)
  * Secondary Accent: `#2B4C3F` (хвойный скандинавский)
  * Text Primary: `#111827`, Text Muted: `#6B7280`
* **Типографика:**
  * Заголовки: `Outfit` / `Syne` / `Playfair Display` (акцентные, с выверенным трекингом)
  * Основной текст: `Inter` / `Plus Jakarta Sans` (максимальная читаемость)
* **Интерактив:** плавные микро-анимации наведения, аккордеоны, модальные окна, индикатор прогресса квиза.

---

## 3. Технологический стек

* **Фреймворк:** Next.js (App Router, React 19, TypeScript)
* **Стилизация:** CSS Modules / Vanilla Modern CSS (CSS Variables, Flexbox/Grid, clamp typography, media queries)
* **Иконки:** Lucide React
* **Валидация форм:** Zod
* **Уведомления / Toast:** Sonner / кастомный Toast-компонент
* **API / Backend:** Next.js Route Handlers (`/api/lead`) с отправкой в Telegram Bot / Webhook CRM и симуляцией сохранения в базу данных

---

## 4. Архитектура и структура страниц / компонентов

### 4.1. Header & Навигация
* Фиксированный / плавающий бар со сглаженным блюром (`backdrop-filter: blur(12px)`).
* Навигация: *Проекты*, *Калькулятор*, *Услуги*, *Этапы*, *О компании*, *Контакты*.
* Прямой номер телефона, индикатор доступности инженера («Онлайн, ответ за 5 мин»), кнопка быстрого вызова квиза («Рассчитать смету»).

### 4.2. Hero Section
* Высококачественный фоновый визуал современного загородного дома скандинавского стиля.
* Продающий заголовок: *«Проектирование и строительство энергоэффективных домов под ключ с фиксированной сметой в договоре»*.
* Тройка ключевых преимуществ с иконками:
  * 0 руб. переплат (фиксируем цену до начала работ)
  * 10 лет официальной гарантии по договору
  * 140+ реализованных объектов за 12 лет работы
* Главные CTA: кнопка «Рассчитать стоимость онлайн» (скролл к квизу) и «Смотреть каталог проектов».

### 4.3. Интерактивный Квиз-Калькулятор стоимости (Ключевая конверсионная фича)
* **Шаг 1: Технология строительства:**
  * Газобетонные блоки (D400/D500)
  * Скандинавский фахверк (панорамное остекление)
  * Каркасный энергоэффективный дом
  * Керамический блок / Кирпич
* **Шаг 2: Площадь и этажность:**
  * Интерактивный ползунок площади (от 80 до 450 м²)
  * Выбор этажности (1 этаж, 1.5 этажа с мансардой, 2 этажа, 3 этажа)
  * Динамический живой пересчет ориентировочной вилки стоимости в реальном времени.
* **Шаг 3: Комплектация:**
  * «Теплый контур» (фундамент + стены + кровля + окна)
  * «White Box» (+ разводка инженерии, штукатурка, стяжка)
  * «Под ключ с чистовой отделкой» (заезжай и живи)
* **Шаг 4: Дополнительные опции:**
  * Терраса / Патио
  * Гараж / Навес на 2 авто
  * Панорамная сауна / Баня
  * Ландшафтный дизайн и забор
* **Шаг 5: Получение расчета и фиксация скидки:**
  * Показ предварительной сметы и бонуса (бесплатный геологический анализ участка + 3D-проект).
  * Поля ввода: Имя, Телефон, Удобный способ связи (Telegram / WhatsApp / Звонок).
  * Мгновенный сабмит на `/api/lead` с красивым экраном благодарности.

### 4.4. Каталог проектов и Кейсы (Portfolio)
* Вкладки фильтрации: *Все проекты*, *Одноэтажные*, *Двухэтажные*, *Фахверк*, *Премиум*.
* Карточка объекта:
  * Фото экстерьера + бейдж площади и срока строительства.
  * Параметры: площадь (м²), спальни, санузлы, габариты, цена проекта.
  * Кнопка «Подробнее о проекте» (открывает модальное окно с поэтажными планировками, сметой и характеристиками).

### 4.5. Услуги и прозрачное ценообразование
* Индивидуальное архитектурное проектирование.
* Строительство домов и коттеджей.
* Монтаж инженерных систем (отопление, умный дом, водоочистка).
* Внутренняя отделка и дизайн интерьера.

### 4.6. Пошаговый процесс и технадзор (Stages & Trust)
* 6 прозрачных этапов: Геология и проектирование → Фундамент и плита → Коробка и кровля → Инженерия → Отделка → Сдача и гарантия.
* Блок «Почему клиенты выбирают нас»: фотоинспекция, онлайн-камеры на объекте 24/7, поэтапная оплата.

### 4.7. FAQ & Контакты
* Аккордеон с частыми вопросами (сроки, ипотека/эскроу-счета, что если смета вырастет, гарантийные случаи).
* Блок контактов с картой, графиком работы офиса и формой экспресс-консультации с главным инженером.

## 5. Интеграции и логика API

* **Эндпоинт:** `POST /api/lead`
* **Обработка данных:**
  * Валидация типов через Zod.
  * Санитизация полей.
  * Форматирование сообщения в HTML / Markdown для Telegram Bot API (если указаны переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, отправляется реальный запрос; если не указаны — эмулируется успешный ответ с подробным логом).
  * Защита от спама (honeypot + rate limit по IP).
