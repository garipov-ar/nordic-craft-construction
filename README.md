## 📌 О проекте (Case Study)

Проект разработан на основе реального коммерческого технического задания с фриланс-биржи.

* **Сфера бизнеса:** Малоэтажное индивидуальное жилищное строительство (ИЖС).
* **Цель:** Прямые продажи загородных домов, квалификация входящих заявок и повышение конверсии через интерактивные инструменты расчета сметы.
* **Стиль & Дизайн:** «Nordic / Premium Minimal» — строгая скандинавская эстетика без визуального шума, теплая палитра (графит, глина, золото, хвоя), сбалансированная типографика и плавная микро-анимация.

## ✨ Ключевой функционал

### 1. 🧮 Интерактивный 5-шаговый Квиз-Калькулятор стоимости
* **Шаг 1. Технология возведения:** Газобетон D400/D500, Скандинавский фахверк, Энергоэффективный каркас, Керамический крупноформатный блок.
* **Шаг 2. Параметры дома:** Плавный ползунок площади (80–400 м²) и выбор этажности (1, 1.5, 2, 3 эт.).
* **Шаг 3. Комплектация:** «Теплый контур», «White Box (предчистовая отделка)», «Под ключ с чистовой отделкой».
* **Шаг 4. Дополнительные строения:** Крытая терраса, навес на 2 авто, панорамная сауна, ландшафтный дизайн.
* **Шаг 5. Захват лида и фиксация бонусов:** Маска ввода телефона, выбор мессенджера (Telegram / WhatsApp / Звонок).
* **⚡ Live Sidebar:** Динамический мгновенный пересчет вилки сметы, ориентировочного срока строительства и ежемесячного платежа по льготной ипотеке от 6%.

### 2. 🏛 Каталог авторских проектов с модальными окнами
* Вкладки фильтрации: *Все проекты*, *Одноэтажные*, *Двухэтажные*, *Фахверк*, *Премиум*.
* Интерактивная карточка: фотогалерея, габаритные размеры, спальни, санузлы, сроки возведения, цена.
* Детальный модал: поэтажные планировки, спецификации высоты потолков, несущих конструкций и кнопка заказа сметы.

### 3. 🛠 Интерактивный роадмап «6 этапов строительства»
* Пошаговая карта от геологического анализа и фундамента до передачи ключей с паспортом объекта.
* Перечень выдаваемых скрытых актов, протоколов испытаний бетона и схем разводки инженерии.

### 4. 🔒 Блоки доверия и конверсии
* **TrustStats:** Метрики опыта (12 лет, 140+ домов, 10 лет гарантии, 0 ₽ скрытых переплат).
* **Guarantees:** 4 ключевые юридические гарантии безопасности и видеоконтроль 24/7.
* **FAQ Accordion:** Интерактивные ответы на вопросы клиентов (эскроу, ипотека, фиксация сметы).
* **ConsultationCTA:** Форма бронирования бесплатного выезда главного инженера с нивелиром на участок.

### 5. 🤖 API и интеграция с Telegram Bot / CRM
* Маршрут `POST /api/lead` с валидацией через библиотеку **Zod**.
* Форматирование заявок в HTML для Telegram Bot API с подробной информацией о параметрах квиза.
* Встроенный режим симуляции (mock) для тестирования без необходимости настройки токенов.

### 6. 🔍 SEO & Производительность
* Полная семантическая верстка (HTML5).
* Микроразметка **Schema.org JSON-LD** (`HomeAndConstructionBusiness`, `FAQPage`).
* Оптимизация шрифтов и ассетов через `next/font`.
* 100% адаптивность (Mobile-First, Tablet, Desktop).

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/nordic-craft-construction.git
cd nordic-craft-construction
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения (Опционально для Telegram)
Создайте файл `.env.local` в корне проекта:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHAT_ID=-1001234567890
```
*(Если переменные не заданы, сервер будет логировать заявки в консоль в режиме имитации).*

### 4. Запуск локального dev-сервера
```bash
npm run dev
```
Откройте в браузере [http://localhost:3000](http://localhost:3000).

### 5. Сборка для продакшена
```bash
npm run build
npm run start
```
